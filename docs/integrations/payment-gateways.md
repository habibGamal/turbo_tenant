# بوابات الدفع الإلكتروني (Paymob و Kashier)

تتيح لك هذه الصفحة تجهيز بيانات الربط من لوحة بوابة الدفع (**Paymob** أو **Kashier**) وإدخالها في متجرك لاستقبال المدفوعات بالبطاقات البنكية والمحافظ الإلكترونية.

::: warning تنبيه
تظهر إعدادات بوابات الدفع عند تفعيل إضافة **Payment Processing & Gateways** من [سوق الإضافات](/admin/plugins).
:::

افتح <span class="path">الإعدادات والنظام › إعدادات المتجر › المالية وبوابات الدفع</span> ثم اتبع خطوات البوابة التي تستخدمها.

## أولاً: ربط بوابة Paymob

<div class="steps">

1. في لوحة تحكم Paymob، انسخ **المفتاح العام (Public Key)** و**المفتاح السري (Secret Key)** و**مفتاح HMAC السري** و**معرفات الدمج (Integration IDs)**.
2. في إعدادات Paymob داخل لوحة البوابة، ضع رابط الإشعارات (Transaction Processed Callback URL):
   `https://<دومين متجرك>/api/webhooks/paymob`
3. في لوحة المتجر، اختر بوابة الدفع **Paymob** وأدخل الرابط الأساسي (`https://accept.paymob.com`) والمفاتيح ومعرفات الدمج مفصولة بفواصل والعملة (`EGP`).
4. اختر وضع التشغيل `test` للتجربة ببطاقة اختبارية، ثم حوّله إلى `live` بعد التأكد من نجاح الدفع وتحديث حالة الطلب.

</div>

## ثانياً: ربط بوابة Kashier

<div class="steps">

1. في لوحة تحكم Kashier، انسخ **معرف التاجر (Merchant ID)** و**مفتاح API العام** و**المفتاح السري**.
2. في لوحة Kashier، ضع رابط الإشعارات (Server Webhook URL):
   `https://<دومين متجرك>/api/webhooks/kashier`
3. في لوحة المتجر، اختر بوابة الدفع **Kashier** وأدخل المفاتيح والعملة (`EGP`) وحدد **طرق الدفع المسموحة** (بطاقة أو محفظة أو كليهما).
4. جرّب عملية دفع كاملة في وضع `test` قبل التحويل إلى `live`.

</div>

::: tip نصيحة
لا تغيّر حالة الدفع يدوياً إذا تأخر تأكيد الدفع؛ راجع صحة رابط الإشعارات (Webhook) ومفتاح التحقق السري، وتابع تفاصيل قواعد الدفع في صفحة [الدفع الإلكتروني](/admin/payments).
:::
