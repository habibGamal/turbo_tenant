# ربط بكسل ميتا وكتالوج المنتجات

تتيح لك هذه الصفحة ربط متجرك بإعلانات ميتا (فيسبوك وإنستجرام) لقياس الزيارات والمشتريات بدقة ومزامنة المنتجات تلقائياً مع كتالوج ميتا.

::: warning تنبيه
تظهر هذه الإعدادات عند تفعيل إضافة **Meta Marketing** من [سوق الإضافات](/admin/plugins).
:::

افتح <span class="path">الإعدادات والنظام › إعدادات المتجر › تسويق ميتا (Meta)</span> ثم نفّذ الخطوات التالية:

<div class="steps">

1. أدخل **معرف البكسل (Pixel / Dataset ID)** من Meta Events Manager لمتابعة أحداث التصفح وإضافة السلة والشراء.
2. فعّل **إرسال الأحداث من الخادم إلى ميتا** والصق **رمز الوصول (Access Token)** المستخرج من إعدادات Conversions API في Events Manager.
3. فعّل **تفعيل رابط تصدير الكتالوج** واضغط **توليد مفتاح جديد**، ثم أضف رابط التغذية المجدولة في Meta Commerce Manager (`https://<دومين متجرك>/meta/catalog/<المفتاح>.csv` أو `.xml`، ورابط النسخة العربية `.ar.csv`).
4. افتح <span class="path">المحتوى والتسويق › تشخيص تكامل ميتا</span> للتحقق من الاتصال وسجل الأحداث وتطابق معرفات المنتجات.

</div>

::: tip نصيحة
استخدم رمز أحداث الاختبار ووضع التصحيح أثناء التجربة فقط، ثم امسحهما عند الانتهاء. للمزيد من التفاصيل حول خيارات الشاشة راجع [ميتا والكتالوج](/admin/meta).
:::
