# تسجيل الدخول بحساب جوجل

تتيح هذه الصفحة لمدير المتجر تفعيل خيار **تسجيل الدخول بحساب جوجل** ليتمكن العملاء من الدخول والطلب بسرعة دون إنشاء كلمة مرور جديدة.

افتح <span class="path">الإعدادات والنظام › إعدادات المتجر › النظام وساعات العمل</span> وانتقل إلى قسم **الربط مع Google** ثم نفّذ الخطوات التالية:

<div class="steps">

1. أنشئ بيانات OAuth 2.0 Web Client في Google Cloud Console.
2. أضف رابط العودة المعتمد (Authorized redirect URI) بصيغة:
   `https://<دومين متجرك>/auth/google/callback`
3. انسخ **Client ID** و**Client Secret** من Google Cloud Console.
4. الصقهما في حقلي **الربط مع Google** داخل [إعدادات المتجر](/admin/store-settings#النظام-وساعات-العمل)، واكتب رابط العودة نفسه ثم اضغط **حفظ**.

</div>

::: warning تنبيه
تأكد من تطابق الدومين في رابط العودة حرفياً مع دومين متجرك وبروتوكول `https`، وإلا فستظهر للعميل رسالة تعذر تسجيل الدخول بحساب جوجل.
:::
