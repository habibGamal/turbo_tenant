# إعدادات المتجر

الشاشة: <span class="path">الإعدادات والنظام › إعدادات المتجر</span>. الإعدادات مقسمة لتبويبات، وأي إضافة ليها إعدادات بتضيف تبويب خاص بيها. اضغط **حفظ** بعد التعديل، والتغيير بيظهر على الموقع فوراً.

## الهوية والمتجر

- اسم المتجر بالعربي والإنجليزي، والوصف.
- **الشعارات والوسائط**: الشعار، شعار SVG (اختياري)، أيقونة المتصفح (Favicon)، وصورة بديلة للمنتجات اللي ملهاش صورة.
- بيانات التواصل: البريد، الموبايل، العنوان.
- **روابط التواصل الاجتماعي**: فيسبوك، إنستجرام، X، وروابط إضافية.

## المظهر والألوان

- **السمة الجاهزة**: سمات جاهزة (Default، Terracotta، Emerald، Ocean، Amber، Burgundy) بتملأ الألوان واستدارة الحواف تلقائياً.
- **تخصيص الألوان والحواف**: **اللون الأساسي** (الأزرار والعناصر البارزة)، **اللون الثانوي** (الخلفيات الهادئة والبطاقات)، و**درجة انحناء الحواف**.

## بطاقات الواجهة

كروت ترويجية قصيرة بتظهر في واجهة الموقع (مثلاً: توصيل سريع، مكونات طازة). لكل كارت: **عنوان البطاقة**، **الوصف الترويجي**، و**أيقونة / صورة البطاقة**.

## النظام وساعات العمل

- **إعدادات النظام والتشغيل**: العملة، ووضع الصيانة (يقفل الموقع مؤقتاً).
- **أوقات وساعات العمل**: ساعات كل يوم، أيام الإجازة، وفترات بتعدي نص الليل. وخيار **استقبال الطلبات خارج أوقات العمل**.
- **الربط مع Google**: بيانات تسجيل الدخول بحساب جوجل للعملاء.
- **إعدادات البريد الإلكتروني (SMTP)**: السيرفر اللي بيبعت إيميلات المتجر (زي استعادة كلمة المرور).

::: warning ساعات العمل بتوقيت UTC
الموقع بيقارن ساعات العمل بساعة السيرفر بتوقيت UTC (مصر = UTC+2، أو +3 في التوقيت الصيفي). لو العملاء بيشوفوا «We are currently closed» وأنتم فاتحين، راجع الساعات أو فعّل استقبال الطلبات خارج أوقات العمل.
:::

## الطلبات

تبويب **الطلبات** (من إضافة الطلبات):

- **نسبة الضريبة المضافة (%)**.
- **الحد الأدنى لقيمة الطلب**: لو السلة أقل منه العميل مش هيقدر يطلب.
- **السماح بالتعديل اليدوي لحالة الطلبات من لوحة الإدارة**: الطبيعي إن حالة الطلب بتتحدث من الكاشير في الفرع. فعّل الخيار ده بس لو محتاج تغيّر الحالة بنفسك (مثلاً فرع من غير نقطة بيع).
