# ميتا (فيسبوك وإنستجرام) والكتالوج

إضافة **Meta Marketing** بتربط متجرك بإعلانات ميتا: البكسل بيتابع زوار الموقع، وConversions API بيبعت المشتريات من السيرفر (أدق ومش بيتأثر بمانع الإعلانات)، والكتالوج بيخلي منتجاتك تظهر في إعلانات الكتالوج والمتجر.

الشاشة: <span class="path">إعدادات المتجر › تسويق ميتا (Meta)</span>.

## 1. البكسل

- **معرف البكسل (Pixel / Dataset ID)** من Events Manager.
- **وضع التصحيح للبكسل**: للتجربة فقط.

## 2. إرسال الأحداث من السيرفر

- فعّل **إرسال الأحداث من الخادم إلى ميتا**.
- **رمز الوصول (Access Token)**: من Events Manager ← الإعدادات ← Conversions API ← Generate access token.
- **رمز أحداث الاختبار (Test Event Code)**: أثناء التجربة بس، وامسحه بعدها.

المشتريات بتتبعت بعد تأكيد الطلب (الدفع عند الاستلام فوراً، والأونلاين بعد تأكيد الدفع). ميتا بتشيل التكرار بين البكسل والسيرفر تلقائياً.

## 3. الكتالوج

<div class="steps">

1. فعّل **تفعيل رابط تصدير الكتالوج**.
2. **مفتاح رابط الكتالوج**: اضغط **توليد مفتاح جديد**.
3. **العلامة التجارية في الكتالوج**: اسم البراند.
4. في Commerce Manager: Catalog ← Data sources ← Data feed ← Scheduled feed، والرابط: `https://<دومين متجرك>/meta/catalog/<المفتاح>.csv` (أو `.xml`).
5. أضف نسخة اللغة العربية (Language override) بالرابط `https://<دومين متجرك>/meta/catalog/<المفتاح>.ar.csv`.

</div>

## التأكد إن كل حاجة شغالة

<span class="path">المحتوى والتسويق › تشخيص تكامل ميتا</span>، بتبويباته: **الحالة والاتصال**، **سجل الأحداث** (آخر الأحداث المبعوتة ونتيجتها)، **كتالوج المنتجات** (مشاكل المنتجات في الكتالوج)، و**تطابق المعرّفات** (إن أرقام المنتجات في البكسل هي نفسها في الكتالوج).

::: tip
المنتجات بالوزن بتتبعت لميتا بكمية 1 وبسعر الكيلو، عشان تطابق السعر في الكتالوج. (تحديث قيد المراجعة.)
:::
