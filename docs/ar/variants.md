# التنويعات (الأحجام)

التنويع هو شكل أو حجم للمنتج بسعر مختلف: صغير / وسط / كبير، أو "فراخ / لحمة". العميل لازم يختار واحد منهم.

## إضافة تنويعات

<div class="steps">

1. افتح المنتج من <span class="path">الكتالوج والمنتجات › المنتجات</span> واحفظه الأول لو جديد.
2. انزل لجدول **التنويعات** واضغط **إضافة تنويع** (أو **إضافة أول تنويع**).
3. اكتب **الاسم** و**الاسم بالعربية**، و**السعر** (سيبه فاضي عشان ياخد السعر الأساسي للمنتج)، و**ترتيب العرض**، و**متاح للطلب**.
4. للسرعة: **إضافة سريعة للتنويعات** ← اكتب الأسماء واضغط Enter بعد كل اسم، وبعدين عدّل الأسعار.

</div>

- لو حجم خلص مؤقتاً، اقفل **متاح للطلب** بدل ما تحذفه. العميل مش هيشوفه.
- لتطبيق نفس الأحجام على كذا منتج: من جدول المنتجات حدد المنتجات ← **إضافة متغيرات سريعة**.
- مع نقطة البيع: ممكن تربط كل حجم بصنف مختلف على الكاشير. [التفاصيل](pos.md#ربط-المنتجات-بأصناف-الكاشير).
