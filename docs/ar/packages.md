# باقات التوفير

الباقة وجبة مجمعة بسعر واحد، فيها مجموعات اختيار للعميل (مثلاً: اختار ساندوتش + اختار مشروب + بطاطس). الشاشة: <span class="path">العروض والخصومات › باقات التوفير</span>.

## إنشاء باقة

<div class="steps">

1. **بيانات الباقة**: **صورة الباقة**، **الاسم / الاسم (عربي)** (واحد منهم على الأقل)، **الوصف**، **سعر الباقة**.
2. **التوفير**: **السعر الأصلي** و**نسبة الخصم** بيظهروا للعميل كقيمة التوفير، وبيتحسبوا تلقائياً من **القيمة الإفرادية المقدرة** (سعر المكونات لو اتطلبت لوحدها).
3. **الصلاحية والظهور**: **صالح من / صالح حتى**، **نشط**، **مميز**، و**السماح باستخدام كوبونات الخصم** على الباقة. وكمان الشارة، الأيقونة، لون الكارت، وترتيب العرض.
4. **المجموعات**: لكل مجموعة **اسم المجموعة**، الوصف، نوع الاختيار (اختيار واحد / اختيار متعدد)، الحد الأدنى والأقصى، والسماح بالتكرار.
5. **عناصر كل مجموعة**: المنتج، والحجم إما ثابت أو "اختيار العميل" (الحجم الأغلى بيتحسب فرقه)، الكمية، فرق السعر، عنصر افتراضي، و**السماح بالإضافات** (إضافات المنتج نفسه).
6. **قواعد البيع**: مواعيد التوفر الأسبوعية (ممكن تعدّي نص الليل، ومن غير مواعيد = متاحة دايماً)، الفروع (من غير اختيار = كل الفروع)، نوع الطلب (توصيل / استلام)، الحد الأقصى في الطلب الواحد، والحد اليومي.
7. **تكاملات** (لو نقطة البيع مفعلة): اربط الباقة بصنف واحد على الكاشير لكل الفروع أو لكل فرع، أو سيبها تنزل كمكوناتها.

</div>

عند الحفظ، اللوحة بتراجع القواعد وتقولك لو فيه مشكلة، مثلاً: "اختيار واحد" لازم حده الأدنى والأقصى 1، أو المنتجات بالوزن مش مسموحة، أو مواعيد متداخلة.

## متابعة الباقات

- عمود **الحالة** في الجدول: غير نشطة / منتهية / مجدولة / غير مكتملة / نفدت اليوم / خارج أوقات التوفر / متاحة.
- عمود نقطة البيع: مربوطة / مكونات مربوطة / غير مربوطة.
- ودجت أعلى الصفحة: الوحدات المباعة، الإيراد، متوسط السعر، أكثر الباقات مبيعاً، وأكثر الاختيارات طلباً في كل مجموعة.
- إجراءات: **نسخ الباقة**، وتفعيل / إيقاف جماعي.

## العميل بيشوف إيه

الباقات بتظهر في الرئيسية وصفحة الباقة، والكارت بيوضح التوفير، المحتوى، مواعيد التوفر، "توصيل فقط" أو "استلام فقط"، و"متبقي N اليوم". خارج المواعيد أو لو خلصت، زر الإضافة للسلة بيتقفل مع توضيح السبب. صفحة أي منتج بتعرض لحد 3 باقات فيها المنتج ("اجعلها وجبة").
