# باقات التوفير

الباقة وجبة مجمعة بسعر واحد، فيها مجموعات اختيار للعميل (مثلاً: اختر ساندويتشاً + اختر مشروباً + بطاطس). الشاشة: <span class="path">العروض والخصومات › باقات التوفير</span>.

## إنشاء باقة

<div class="steps">

1. **بيانات الباقة**: **صورة الباقة**، و**الاسم / الاسم (عربي)** (أحدهما على الأقل)، و**الوصف**، و**سعر الباقة**.
2. **التوفير**: **السعر الأصلي** و**نسبة الخصم** يظهران للعميل قيمةً للتوفير، ويُحسبان تلقائياً من **القيمة الإفرادية المقدرة** (سعر المكونات لو طُلبت منفردة).
3. **الصلاحية والظهور**: **صالح من / صالح حتى**، و**نشط**، و**مميز**، و**السماح باستخدام كوبونات الخصم** على الباقة. وكذلك الشارة، والأيقونة، ولون البطاقة، وترتيب العرض.
4. **المجموعات**: لكل مجموعة **اسم المجموعة**، والوصف، ونوع الاختيار (اختيار واحد / اختيار متعدد)، والحد الأدنى والأقصى، والسماح بالتكرار.
5. **عناصر كل مجموعة**: المنتج، والحجم إما ثابت أو «اختيار العميل» (يُحسب فرق الحجم الأغلى)، والكمية، وفرق السعر، والعنصر الافتراضي، و**السماح بالإضافات** (إضافات المنتج نفسه).
6. **قواعد البيع**: مواعيد التوفر الأسبوعية (قد تمتد بعد منتصف الليل، وبدون مواعيد تكون متاحة دائماً)، والفروع (بدون اختيار = كل الفروع)، ونوع الطلب (توصيل / استلام)، والحد الأقصى في الطلب الواحد، والحد اليومي.
7. **تكاملات** (إذا كانت نقطة البيع مفعلة): اربط الباقة بصنف واحد على الكاشير لكل الفروع أو لكل فرع، أو اتركها تصل بمكوناتها.

</div>

عند الحفظ تراجع اللوحة القواعد وتنبهك إلى أي مشكلة، مثل: «اختيار واحد» يجب أن يكون حده الأدنى والأقصى 1، أو المنتجات بالوزن غير مسموحة، أو المواعيد متداخلة.

## متابعة الباقات

- عمود **الحالة** في الجدول: غير نشطة / منتهية / مجدولة / غير مكتملة / نفدت اليوم / خارج أوقات التوفر / متاحة.
- عمود نقطة البيع: مربوطة / مكونات مربوطة / غير مربوطة.
- عناصر أعلى الصفحة: الوحدات المباعة، والإيراد، ومتوسط السعر، والباقات الأكثر مبيعاً، والاختيارات الأكثر طلباً في كل مجموعة.
- إجراءات: **نسخ الباقة**، والتفعيل أو الإيقاف الجماعي.

## ماذا يرى العميل

تظهر الباقات في الصفحة الرئيسية وصفحة الباقة، وتوضح البطاقة التوفير، والمحتوى، ومواعيد التوفر، و«توصيل فقط» أو «استلام فقط»، و«متبقٍ N اليوم». خارج المواعيد أو عند النفاد يُغلق زر الإضافة إلى السلة مع توضيح السبب. وتعرض صفحة أي منتج حتى 3 باقات تحتوي المنتج («اجعلها وجبة»).
