# مرحباً بك في دليل المتجر

هذا الدليل مخصص لمدير المتجر وفريق التشغيل لإدارة الموقع بالكامل بدون تفاصيل برمجية: من بناء المنيو وضبط التوصيل، إلى استقبال الطلبات ومتابعة الدفع والتسويق.

## ماذا تحصل عليه في متجرك؟

كل متجر يعمل مستقلاً على الدومين الخاص به مع قاعدة بيانات منفصلة، ويتكون من:

| الجزء | لمن | الوظيفة |
| --- | --- | --- |
| **واجهة المتجر** | العملاء | تصفح المنيو، السلة، إتمام الطلب، تتبع الطلب، وتطبيق الويب (PWA) |
| **لوحة الإدارة** | مدير المتجر | `/admin`: المنيو، الطلبات، الفروع والتوصيل، العملاء، الكوبونات، والإعدادات |
| **سوق الإضافات** | مدير المتجر | تشغيل أو إيقاف كل ميزة حسب حاجة متجرك دون تعقيد |

كل الشاشات المذكورة في هذا الدليل موجودة داخل **لوحة الإدارة** على رابط متجرك:

```text
https://<دومين متجرك>/admin
```

أسماء القوائم مكتوبة كما تظهر في اللوحة، مثل <span class="path">الكتالوج والمنتجات › المنتجات</span>.

::: tip نصيحة
إذا لم تجد شاشة أو قسماً مذكوراً في هذا الدليل، فغالباً الإضافة الخاصة به غير مفعلة في [سوق الإضافات](/admin/plugins).
:::

## أبرز مميزات النظام

- **المنيو والكتالوج**: فئات مرتبة، منتجات بوصف وصور مضغوطة تلقائياً، أحجام وتنويعات متعددة، مجموعات إضافات بحدود اختيار، بيع بالوزن، أقسام للواجهة الرئيسية، وباقات التوفير.
- **الفروع والتوصيل**: فروع متعددة، محافظات ومناطق بتكلفة توصيل مستقلة لكل منطقة، شحن مجاني تلقائي عند حد معين، وخيار نموذج العنوان المبسّط.
- **الطلبات والدفع**: استقبال طلبات التوصيل والاستلام من الفرع، إمكانية الطلب كزائر بدون حساب، تتبع حالة الطلب، الدفع عند الاستلام، وبوابات الدفع الإلكتروني عبر Paymob أو Kashier.
- **الربط مع نقطة البيع (POS)**: إرسال الطلبات تلقائياً إلى كاشير الفرع، واستيراد المنتجات، ومزامنة الأسعار، وتحديث حالة الطلب على الموقع فور تحريكها من الكاشير.
- **التسويق والعملاء**: كوبونات خصم بشروط دقيقة، سلايدر ترويجي، صفحات محتوى ثابتة (CMS)، تقييمات العملاء بالصور، المفضلة، إشعارات التطبيق (Push)، وبكسل ميتا وConversions API وكتالوج المنتجات.
- **الهوية والمظهر**: سمات ألوان جاهزة أو مخصصة، اسم وشعار، أزرار تواصل وواتساب عائم، تسجيل الدخول بحساب جوجل، وساعات عمل لكل يوم.
