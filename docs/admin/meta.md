# ميتا (فيسبوك وإنستجرام) والكتالوج

تربط إضافة **Meta Marketing** متجرك بإعلانات ميتا: يتابع البكسل زوار الموقع، وترسل Conversions API المشتريات من الخادم (أدق ولا تتأثر بمانع الإعلانات)، ويجعل الكتالوج منتجاتك تظهر في إعلانات الكتالوج والمتجر.

الشاشة: <span class="path">إعدادات المتجر › تسويق ميتا (Meta)</span>.

## 1. البكسل

- **معرف البكسل (Pixel / Dataset ID)** من Events Manager.
- **وضع التصحيح للبكسل**: للتجربة فقط.

## 2. إرسال الأحداث من الخادم

- فعّل **إرسال الأحداث من الخادم إلى ميتا**.
- **رمز الوصول (Access Token)**: من Events Manager ← الإعدادات ← Conversions API ← Generate access token.
- **رمز أحداث الاختبار (Test Event Code)**: أثناء التجربة فقط، ثم احذفه.

تُرسل المشتريات بعد تأكيد الطلب (الدفع عند الاستلام فوراً، والدفع الإلكتروني بعد تأكيد الدفع). وتحذف ميتا التكرار بين البكسل والخادم تلقائياً.

## 3. الكتالوج

<div class="steps">

1. فعّل **تفعيل رابط تصدير الكتالوج**.
2. **مفتاح رابط الكتالوج**: اضغط **توليد مفتاح جديد**.
3. **العلامة التجارية في الكتالوج**: اسم العلامة التجارية.
4. في Commerce Manager: Catalog ← Data sources ← Data feed ← Scheduled feed، والرابط: `https://<دومين متجرك>/meta/catalog/<المفتاح>.csv` (أو `.xml`).
5. أضف نسخة اللغة العربية (Language override) بالرابط `https://<دومين متجرك>/meta/catalog/<المفتاح>.ar.csv`.

</div>

## التأكد من أن كل شيء يعمل

<span class="path">المحتوى والتسويق › تشخيص تكامل ميتا</span>، بتبويباته: **الحالة والاتصال**، و**سجل الأحداث** (آخر الأحداث المرسلة ونتيجتها)، و**كتالوج المنتجات** (مشكلات المنتجات في الكتالوج)، و**تطابق المعرّفات** (أن أرقام المنتجات في البكسل هي نفسها في الكتالوج).

::: tip
تُرسل المنتجات بالوزن إلى ميتا بكمية صحيحة وبسعر الكتالوج، لتطابق السعر في الكتالوج.
:::
