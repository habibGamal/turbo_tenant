# الكوبونات

الشاشة: <span class="path">العروض والخصومات › الكوبونات › إنشاء</span>. في النموذج 3 تبويبات:

## الخصم والرمز

| الحقل | ملاحظات |
| --- | --- |
| رمز الكوبون (البروموكود) | ما يكتبه العميل، مثل `RAMADAN25` |
| اسم الحملة الترويجية، ووصف الكوبون وشروطه للعملاء | |
| نوع الخصم، وقيمة الخصم | نسبة مئوية أو مبلغ ثابت |
| تاريخ ووقت الانتهاء | |
| الحد الأقصى لمرات الاستخدام | لكل العملاء |
| كوبون نشط | |

## شروط الطلب والمنتجات

- **الحد الأدنى / الأقصى لقيمة الطلب**.
- **نطاق تطبيق الكوبون**: كل المنتجات، أو منتجات محددة، أو فئات محددة، أو نوع سطر (مثل الباقات). يُحسب الخصم على الجزء المشمول فقط.

## القيود والشحن والتوقيت

- **يمنح شحناً مجانياً**، ومعه **الحد الأدنى للشحن المجاني** (اختياري). هذا خاص بالكوبون، وهو مستقل عن الشحن المجاني التلقائي في [إعدادات المتجر](store-settings.md#الطلبات).
- **المحافظات / المناطق القابلة للتطبيق**.
- **صالح للطلب الأول للعميل فقط**.
- **لمستخدمين محددين فقط** ← اختر المستخدمين.
- **أيام الأسبوع الصالحة**، و**صالح من / حتى الساعة** (بتوقيت UTC، مثل ساعات العمل).

## المتابعة

في الكوبون: **عدد مرات الاستخدام** و**إجمالي الخصم الممنوح**.

## ملاحظات

- يكتب العميل الرمز في صفحة إتمام الطلب، ويرى الخصم أو سبب الرفض. ويُراجَع الكوبون مرة أخرى لحظة تأكيد الطلب.
- تدخل الباقات في الكوبون فقط إذا كان خيار **السماح باستخدام كوبونات الخصم** مفعلاً في الباقة.
